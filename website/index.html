Everything a local PHP stack needs

Add a folder and it's online. Open Herd writes the nginx vhosts, the hosts file entries and the certificates for you.

Sites at name.test

Add a project or scan a whole folder. Laravel, CodeIgniter 3/4, WordPress, SPAs and static sites get the right document root automatically.

PHP 5.6 – 8.5

Install any version from windows.php.net (each download checked against a pinned SHA-256) or reuse XAMPP, WAMP or Laragon. One PHP per site, php.ini editor included.

Node.js versions

Install LTS lines from nodejs.org and switch the active version system-wide. Works alongside nvm-windows 1.x and 2.x.

Composer, ready in any terminal

One click installs the composer command for your default PHP, and enables the extensions it needs.

One-click HTTPS

Certificates from mkcert that your browser trusts — no warnings on https://name.test.

Safe with your data

Atomic writes, the hosts file backed up before every change, and nginx / PHP always stopped with the app — even after a crash.

Up and running in five steps

The full guide, troubleshooting included, is in the README.

  1. Run as administratorOpen Herd needs it to add .test entries to the Windows hosts file.
  2. Install a PHP versionOn the PHP page, or press Rescan to pick up the ones you already have.
  3. Download nginxOne click on the Nginx page, the first time only.
  4. Add your projectsAdd a folder with +, or scan your projects directory.
  5. Start allOpen http://name.test, and press Enable HTTPS when you want a padlock.
