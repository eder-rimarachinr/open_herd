What's in it

Everything you'd set up by hand, done for you.

No more editing nginx configs, the hosts file or php.ini by hand. Open Herd writes them, keeps backups, and stops everything cleanly when you quit.

Sites at name.test

Add a project or scan a whole folder. Laravel, CodeIgniter, WordPress, SPAs and static sites get the right document root on their own.

PHP 5.6 to 8.5

Install from windows.php.net, each download checked against a pinned SHA-256, or reuse XAMPP, WAMP or Laragon. A PHP per site, with a php.ini editor.

Node.js versions

Install any LTS line from nodejs.org and switch the active one system-wide. Plays well with nvm-windows 1.x and 2.x.

Composer, built in

One click puts composer in every terminal, on your default PHP, and turns on the extensions it needs.

HTTPS in one click

Certificates from mkcert that your browser trusts. No warnings on https://name.test, ever.

DNS without the hosts file

.test entries are added to and removed from the Windows hosts file for you: one Windows permission prompt when needed, a backup before every change. No need to run the app as administrator.

Legacy projects welcome

End-of-life PHP (5.6 – 8.0) and old Node lines wait behind a toggle, for the client site nobody wants to upgrade.

Safe with your machine

Atomic writes, backups, and nginx / PHP always stopped with the app, even after a crash. PHP restarts on its own if it dies.

Portable mode

Run it from a folder or a USB drive with everything stored next to the exe. Lives quietly in the tray.

Prefer the terminal?

Your tools, on the right versions.

Whatever you pick in Open Herd is what every new terminal gets: the default PHP, Composer on that PHP, and the active Node.

  • composer runs on your default PHP, from any folder.
  • node and npm follow the version you activated, nvm-windows included.
  • A new project is one scan away from https://name.test.

Getting started

From download to https://name.test in four steps.

The full guide, with troubleshooting, is in the README.

STEP 1

Install

Run the installer and open Open Herd. No need to run it as administrator.

open-herd-v0.5.0-setup.exe
STEP 2

Pick a PHP

Install a version on the PHP page, or press Rescan to use the ones you already have.

PHP → Install 8.4
STEP 3

Add projects

Press + for one folder, or scan your projects directory to add them all.

Sites → Scan D:\code
STEP 4

Start all

Your sites answer at name.test. Press Enable HTTPS for the padlock.

https://shop.test
